Kona is the IntelliJ IDEA plugin for the Kona Framework. Use it in IntelliJ IDEA Community or Ultimate, 2024.2 or later.

  1. Install Kona from this page, or download the zip from GitHub Releases and choose Settings → Plugins → ⚙ → Install Plugin from Disk….
  2. Restart IntelliJ IDEA. Installing, updating, or removing the plugin requires a restart.
  3. Open a Kona application and a view under src/main/resources/views (*.crema.html). The editor language is Crema.
  4. Type @ in the view for directives, or wire: on a tag for Brew attributes. Inline template() text blocks (@CremaTemplate or // language=Crema) highlight as Crema too.
  5. Open the Kona tool window on the right and choose Serve (Netty :4000).
  6. Put the caret on a view-name string and press Ctrl+B (⌘B on macOS) to open that file. The same jump works for Crema.view, Brew.view, and Inertia.render.
  7. Optional: Settings → Tools → Kona sets Cadence column completion to migrations, a database connection, or both.

Guide: IntelliJ. Framework: konaframework/kona.
